# Reporte Power BI

## Fuente de datos
SQL Server - Base de datos TURISMOPERU_RARC.

## Modelo
El modelo relaciona las tablas:

RARC.cliente -> RARC.reserva -> RARC.pago

## Medidas
- Total Clientes
- Total Reservas
- Total Ingresos
- Ticket Promedio

## Visualizaciones
- Reservas por estado.
- Ingresos por medio de pago.
- Reservas por fecha.
- Top 10 clientes por cantidad de reservas.
- Ingresos por cliente.

## Principales resultados
El reporte permite analizar el comportamiento de los clientes, las reservas realizadas y los ingresos registrados en el sistema.
